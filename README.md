# TVET Dashboard

Dashboard pengurusan pelajar TVET — dibina dengan HTML, CSS, dan JavaScript tulen.

## 🔗 Live Demo
[![Netlify Status](https://api.netlify.com/api/v1/badges/tvet-dashboard/deploy-status)](https://app.netlify.com/sites/tvet-dashboard/deploys)

## 📋 Ciri-ciri
- **Overview** — Infografik prestasi pelajar (donut chart, bar chart, gauge, trend CGPA, pecahan gred)
- **Akademik** — Rekod akademik dan trend GPA semester
- **Tugasan** — Status tugasan, portfolio, projek dan pembentangan
- **Senarai Pelajar** — Carian, penapis dan paparan detail 200 pelajar
- **Workshop** — Kalender kehadiran dan pencapaian
- **Timeline** — Peta jalan akademik semester

## 🚀 Deploy ke Netlify

### Cara 1 — Drag & Drop
1. Pergi ke [app.netlify.com](https://app.netlify.com)
2. Drag folder projek ini ke ruangan deploy

### Cara 2 — Connect GitHub
1. Pergi ke [app.netlify.com](https://app.netlify.com) → **Add new site** → **Import an existing project**
2. Pilih **GitHub** → pilih repo `tvet-dashboard`
3. Build settings:
   - **Publish directory:** `.`
   - **Build command:** *(kosongkan)*
4. Klik **Deploy site**

## 🛠 Tech Stack
- HTML5 / CSS3 / Vanilla JavaScript
- SVG charts (tiada library luar)
- Fully static — tiada server diperlukan
